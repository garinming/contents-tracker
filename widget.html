Scriptable 앱 받기 (무료)

  1. Scriptable 앱을 설치해요.
  2. 위의 코드 복사를 눌러요.
  3. Scriptable을 열고 오른쪽 위 ＋ → 빈 화면에 붙여넣기 → 제목을 "내 컬렉션"으로 바꿔요.
  4. ▶︎ 실행 버튼을 눌러 웹앱 아이디/비밀번호로 로그인해요. (처음 한 번만)
  5. 홈 화면을 길게 눌러 ＋ → Scriptable → 중간 크기 위젯을 추가해요.
  6. 위젯을 길게 눌러 위젯 편집 → Script에서 "내 컬렉션"을 골라요.

• 비밀번호는 저장되지 않아요. 로그인 토큰만 iPhone 키체인에 보관돼요.

• 위젯은 약 30분마다 새로 고쳐지고, 진행 중인 게 여러 개면 매번 랜덤으로 바뀌어요.

• 일기·리뷰 버튼은 Safari 없이 Scriptable 안에서 바로 쓰기 창이 떠요. 저장 후 아래로 쓸어내려 닫으면 돼요.

• 썸네일을 누르면 Safari에서 그 작품 상세가 열려요.

• 이미 설치했다면 코드를 다시 복사해서 기존 스크립트 내용을 통째로 바꿔주세요.
